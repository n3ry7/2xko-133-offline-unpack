# Notice

**What this repository contains:** original notes and tooling written while studying a
packed retail build. Source code only.

**What it does not contain, and must not:**

- no game executables, archives, assets, or decrypted game data
- no copies of the packed or unpacked `Lion-Win64-Shipping.exe`
- no `stub.dll`, `vService.exe`, or any other third-party binary
- no captured dumps (`text.bin`, `image.bin`, IAT dumps)
- no account credentials, tokens, or logs containing them

**Intended use:** offline archival work on hardware you own, with software you are
licensed to use. The unpacking described here defeats the executable packer, and the
Vanguard stub answers a local named pipe so the game will start without Riot's
anti-cheat present. Both are strictly for **offline, single-machine use**.

**Do not** use any of this to play online, to bypass anti-cheat for competitive play,
or to redistribute game content. Doing so would breach Riot Games' terms of service and
may violate local law.
